# خزنة Cue — نموذج تجريبي

نموذج محلي لإنشاء ملف خزنة مشفّر وفتحه على **Windows وAndroid** من دون رفع الملفات إلى خدمة. التطبيق يعمل في متصفح حديث، ويطلب اختيار الملفات أو ملف الخزنة يدويًا؛ **لا يعمل تلقائيًا عند إدخال USB**.

## التشغيل السريع

### Windows

1. انسخ مجلد المشروع إلى الكمبيوتر أو إلى USB.
2. افتح `Start-CueVault.bat`. إذا كان Python 3 متاحًا، يفتح الصفحة عبر `http://127.0.0.1:8765/CueVault.html` في المتصفح الافتراضي. وإلا يحاول فتح الصفحة المستقلة `CueVault.html` مباشرة.
3. استخدم Chrome أو Edge حديثًا. لا تحتاج إلى اتصال إنترنت.

### Android

1. انسخ الملف المستقل `CueVault.html` إلى الهاتف (أو افتحه من USB عبر مدير الملفات) واختر فتحه في Chrome.
2. اختر **فتح خزنة**، ثم **اختيار ملف .cuevault**. من منتقي ملفات Android اختر USB إذا ظهر ضمن المواقع.
3. عند الإنشاء، يحفظ المتصفح ملف الخزنة في التنزيلات غالبًا؛ انقله يدويًا إلى USB باستخدام تطبيق «الملفات».

يفتح منتقي الملفات النظامي الملفات التي تختارها فقط. يتطلب Web Crypto سياقًا آمنًا؛ `file://` موثوق في المتصفحات المتوافقة، لكن بعض تطبيقات الملفات على Android قد تفتح الصفحة عبر مزوّد URI مختلف. لم يُختبر النموذج على جهاز Android فعلي أو كل مزوّدي ملفات USB. إذا ظهرت رسالة عن Web Crypto، فلا تتجاوز حماية المتصفح؛ جرّب فتح `CueVault.html` في Chrome مباشرة، أو استخدم أصلًا آمنًا موثوقًا.

## الاستخدام

- **إنشاء خزنة:** اختر حتى 200 ملف، بإجمالي لا يتجاوز 40 ميبيبايت، اكتب كلمة مرور وتأكيدها (10 أحرف كحد أدنى، و12+ أفضل)، ثم نزّل ملف `.cuevault` واحفظه على USB.
- **فتح خزنة:** اختر ملف `.cuevault` يدويًا وأدخل كلمة المرور. نزّل الملفات المطلوبة واحدةً واحدة؛ الملفات المنزّلة غير مشفّرة.
- عند الانتهاء اضغط **إغلاق الخزنة** وأغلق الصفحة. أغلقها كذلك قبل فصل USB.
- لتحديث المحتويات في هذا النموذج، أنشئ خزنة جديدة من الملفات المطلوبة؛ لا يدعم تعديل خزنة موجودة.

## الأمان والحدود

- تنسيق `VLT1`: رأس ثابت 52 بايت، `PBKDF2-HMAC-SHA-256` بعدد 600,000 دورة، و`AES-256-GCM` مع salt عشوائي 16 بايت وnonce عشوائي 12 بايت. الرأس موثق ضمن التشفير (AAD). تطبّع كلمة المرور إلى Unicode NFC.
- أرشيف ZIP وأسماء الملفات داخله مشفّرة كليًا. ملف الخزنة يظل معتمًا؛ لكن حجمه الخارجي ظاهر.
- لا يحفظ التطبيق كلمة المرور في التخزين المحلي أو الرابط. إغلاق الخزنة يمسح المراجع المعروضة، لكن JavaScript لا يضمن محو الذاكرة ماديًا فورًا.
- فقدان كلمة المرور يعني عدم القدرة على الاستعادة. احتفظ بنسخة احتياطية من ملف الخزنة؛ التشفير لا يمنع تلف USB أو فقدانه.
- النسخة التجريبية تحمل الملفات مؤقتًا في الذاكرة؛ لا تستخدم ملفات أكبر من الحدود المذكورة. لا توفر حماية من جهاز مصاب أو متصفح/إضافات خبيثة، وليست مراجعة أمنية أو منتجًا نهائيًا.

## بنية الملفات

- `CueVault.html`: نسخة مستقلة جاهزة للنقل.
- `index.html`, `src/`, `vendor/`: مصادر المشروع ونسخة JSZip المضمّنة محليًا.
- `Start-CueVault.bat`: مشغل Windows اختياري.
- `test/`: اختبارات نواة التشفير.

## التحقق محليًا من المصدر

باستخدام Node.js 20 أو أحدث:

```bash
npm ci
npm test
npm run build:standalone
npm run test:browser
```

`npm run test:browser` اختبار إضافي يتطلب Chromium مثبتًا في `/usr/bin/chromium`. يعيد `npm run build:standalone` بناء `CueVault.html` من المصادر؛ لا يحتاج اتصالًا عند وجود الحزم في مجلد `node_modules` بعد التثبيت.
